NimiQuant Crypto Intelligence Engine

Multi-chain cryptocurrency market scanner, signal scoring engine, and live PnL tracking web application bridging established momentum trading and early micro-cap discovery. Polls on-chain liquidity pools and OHLCV candlestick data via the GeckoTerminal API, evaluates multi-timeframe breakouts, delivers real-time HTML-formatted Telegram alerts, and lets traders log positions, monitor live PnL, and export trade logs to CSV.

Core Architecture & Capabilities
  • Hybrid Pool Discovery & Filtering: Queries trending and newly created liquidity pools across Solana, Base, Ethereum, BNB Chain, Arbitrum, and Polygon while filtering native wrapped tokens, deduplicating contracts, and prioritizing low-cap and micro-cap opportunities alongside established runners.
  • Multi-Timeframe Breakout & Conviction Engine: Evaluates 15m, 1h, 7d, and 20d candles to compute a 0–100 conviction score factoring in setup tier, candle volume surge, breakout percentage, market-cap tier bonuses, and Volume-to-Market-Cap (Vol/MC) velocity.
  • Risk, Targets, Telegram & PnL: Generates structured entries, stop-loss levels, and tiered targets (including 2x+ moonbag targets on micro-cap setups), sends HTML alerts with copyable contract addresses and remote /status & /scan Telegram commands, and tracks session PnL with CSV export.
Problem Solved

Standard momentum scanners skew toward large-cap tokens or lag behind fast-moving on-chain launches. NimiQuant unifies multi-timeframe OHLCV verification, micro-cap velocity scoring, risk/target planning, and instant mobile alerts in one workspace.

Engineering & Product Execution

Built an end-to-end data pipeline with 429 retry/backoff and request pacing, stateful UI tabs, two-way Telegram Bot API polling from secrets configuration, and continuous deployment via GitHub and Streamlit Community Cloud.
